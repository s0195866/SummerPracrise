## 📋 Описание предметной области

Интернет-магазин по продаже техники. Клиенты могут просматривать каталог, добавлять товары в корзину, оформлять заказы и оставлять отзывы. Сотрудники (менеджеры/администраторы) управляют заказами, товарами и пользователями через админ-панель.

**Сущности:**

| Сущность       | Описание |
| -------------- | -------- |
| **Клиент**     | ФИО, телефон, email, адрес, роль (`client` / `manager` / `admin`), `total_purchases_amount` (сумма покупок — определяет «постоянного клиента»), `is_blocked` |
| **Товар**      | Название, цена, единица измерения (`шт` / `кг` / `л`), описание, остаток на складе, фото |
| **Заказ**      | Клиент, дата продажи, дата доставки, итоговая сумма (после скидки), статус |
| **Состав заказа** | Товар, количество, **цена на момент покупки** (`price_at_sale`) |
| **Корзина**    | Персональная корзина клиента (1:1 с `client`) |
| **Доставка**   | Адрес, дата, метод, статус (1:1 с `orders`) |
| **Оплата**     | Способ, сумма, статус (1:1 с `orders`) |
| **Отзыв**      | Клиент + товар + оценка (1..5) + текст |

**Бизнес-правила:**

1. Цена товара не может быть отрицательной.
2. Количество товара в заказе больше нуля.
3. Сумма заказа = Σ(`price_at_sale` × `quantity`) по всем позициям.
4. Каждый заказ связан с конкретным клиентом и содержит хотя бы один товар.
5. **Клиент становится «постоянным» при сумме покупок ≥ 5000 руб.**
6. **Постоянный клиент получает скидку 2% на каждый новый заказ.**
7. Цена сохраняется в `order_item.price_at_sale` на момент оформления — изменение цены в `product` не влияет на уже оформленные заказы.
8. После оформления заказа `client.total_purchases_amount` увеличивается на сумму заказа.
9. Складской остаток уменьшается на количество заказанного товара.
10. Статусы заказа: `new → processing → shipped → delivered` (или `cancelled` из `new`/`processing`).

## 🏗 Архитектура

```
                  ┌─────────────────────────┐
                  │  Frontend (React + Vite) │
                  │  - Каталог, корзина      │
                  │  - Личный кабинет        │
                  │  - Админ-панель          │
                  └──────────┬──────────────┘
                             │ HTTP/JSON (REST API)
                             ▼
                  ┌─────────────────────────┐
                  │   Backend (FastAPI)     │
                  │  - бизнес-логика        │
                  │  - скидки, заказы       │
                  │  - аутентификация JWT   │
                  │  - загрузка файлов      │
                  └──────────┬──────────────┘
                             │ asyncpg (SQL)
                             ▼
                  ┌─────────────────────────┐
                  │   PostgreSQL 15         │
                  │   - 9 таблиц            │
                  └─────────────────────────┘
```

Фронтенд и бэкенд общаются по REST API. Фронтенд раздаётся через Nginx, который проксирует `/api/*` запросы на бэкенд.

## 🚀 Быстрый старт (Docker)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/s0195866/SummerPracrise.git
cd SummerPracrise
```

### 2. Настроить переменные окружения

```bash
cp .env.example .env
# При желании отредактируйте .env: пароль БД, JWT_SECRET и т.п.
```

### 3. Поднять сервисы

```bash
docker compose down -v
docker compose up -d --build
```

Поднимутся три контейнера:

| Контейнер       | Назначение                | Порт           |
| --------------- | ------------------------- | -------------- |
| `postgres-db`   | PostgreSQL 15             | `5432`         |
| `shop-backend`  | FastAPI                   | `8000`         |
| `shop-frontend` | Nginx + React (Vite build)| `80`           |

Backend при старте автоматически создаст все таблицы (см. `app/database.py:init_db`). Если `SEED_DB=true` в `.env`, БД заполнится тестовыми данными.

### 4. Открыть приложение

- **Сайт**: http://localhost:80
- **Swagger UI**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc
- **Health**: http://localhost:8000/health

## 🧪 Локальный запуск без Docker

### База данных

```bash
# Создать БД в PostgreSQL
psql -U postgres -c "CREATE DATABASE summer_practice;"

# Создать таблицы и заполнить тестовыми данными
psql -U postgres -d summer_practice -f init.sql
```

### Бэкенд

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux/Mac

pip install -e .
uvicorn app.main:app --reload --port 8000
```

### Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Фронтенд будет доступен на `http://localhost:5173`, бэкенд на `http://localhost:8000`.

## 🧱 Схема БД

| Таблица      | Назначение                                              |
| ------------ | ------------------------------------------------------- |
| `client`     | Клиенты и сотрудники (role: client/manager/admin)       |
| `product`    | Каталог товаров (с полем `photo` для загруженных фото)  |
| `orders`     | Заказы                                                  |
| `order_item` | Состав заказа (с `price_at_sale` на момент покупки)     |
| `cart`       | Корзина клиента (1:1 с `client`)                        |
| `cart_item`  | Строки корзины                                          |
| `delivery`   | Доставка (1:1 с `orders`)                               |
| `payment`    | Оплата (1:1 с `orders`)                                 |
| `review`     | Отзывы клиентов на товары                               |

Для создания таблиц вручную (без Docker) используйте `init.sql`:

```bash
psql -U postgres -d summer_practice -f init.sql
```
