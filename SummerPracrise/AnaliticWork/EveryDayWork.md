User Story
Как клиент, я хочу оформить заказ, чтобы купить выбранные товары и получить их доставку.

Основной сценарий
Пользователь открывает корзину
Система показывает товары
Пользователь нажимает “Оформить заказ”
Система запрашивает адрес
Пользователь вводит адрес
Система рассчитывает стоимость
Пользователь подтверждает заказ
Система создает заказ

Альтернативы
корзина пустая → система блокирует оформление
товар закончился → система удаляет товар из заказа
пользователь не авторизован → перенаправление на логин
